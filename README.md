A dependency-free, fast static-site generator: `solve.js` implements
`run(input)` and returns makefun-site 1.0.0's exact output tree
byte-for-byte, about 2.7x faster than the reference on the practice set
(and exact on 33 verified cases). `main.ts` is the driver: it reads
`/input/cases.json` and writes `/output/answers.json`. No network, no
WebAssembly, no native addons, Node 22 only.

## Run it

```sh
node main.ts
```

It reads `/input/cases.json` and writes `/output/answers.json`.
